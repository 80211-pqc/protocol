# protocol

무선 네트워크(IEEE 802.11) 환경에 **양자내성암호(PQC)를 적용한 프로토콜을 제안·명세화**하는
프로젝트입니다. 세부 구현 단계를 문서로 명세하여, 구현 과정에서 발생할 수 있는 취약점과
버그를 사전에 방지하는 것을 목표로 합니다.

이 레포는 **80211-PQC** 프로젝트의 *프로토콜 명세서* 파트입니다.

## 프로젝트 소개

WPA3-PQC는 기존 무선 보안 프로토콜에 양자내성암호를 결합한 프로토콜을 설계하고,
이를 구현 가능한 수준으로 상세히 명세하는 것을 목표로 합니다.

- 프로토콜을 **제안**하고, 수학적 근거와 함께 **명세화**합니다.
- 구현체(`hostap-pqc`, `openwrt-pqc`)가 참조하는 **설계도**를 제공합니다.
- 세부 구현 단계까지 문서화하여 구현 단계의 취약점·버그를 방지합니다.

## 프로젝트 구성

80211-PQC 프로젝트는 다음 4개 레포로 구성됩니다.

| 레포 | 역할 |
|------|------|
| **protocol** ✅ | 프로토콜 제안 및 구현 명세서 |
| [hostap-pqc](https://github.com/80211-pqc/hostap-pqc) | 프로토콜 실 구현체 |
| [openwrt-pqc](https://github.com/80211-pqc/openwrt-pqc) | 구현된 프로토콜을 적용한 펌웨어 |
| [liboqs-80211](https://github.com/80211-pqc/liboqs-80211) | 802.11 환경에 맞게 최적화된 liboqs 연산 구현체 |

> ℹ️ 이 레포의 명세가 구현 레포들의 기준이 됩니다. 명세와 구현이 어긋나면 명세를 정본으로 봅니다.
